Euclidean Distance Formula
d = √[(x&sub2 - x&sub1)² + (y&sub2 - y&sub1)² + (z&sub2 - z&sub1)²]

Calculates the direct distance between the lens principal point and the detected object centroid in 3D space.

Angular Projection Equation
θ = arctan(f / √(u² + v²))

Maps 2D pixel coordinates (u, v) to a relative angular displacement using focal length (f) constants.
