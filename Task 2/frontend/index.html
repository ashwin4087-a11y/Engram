    System Overview

    OptiVue combines browser UI, FastAPI, OpenCV, and MediaPipe into a live monocular estimation stack.

    Frontend Architecture

    Vanilla JavaScript pipelines status, route switching, polling, and dashboard state updates without framework overhead.

    Backend Architecture

    FastAPI routers expose health, estimate, capture, calibration, and metrics endpoints using a shared service layer.

    MediaPipe Pipeline

    Face landmarks feed the detector service and the tracker state cache that powers frontend metrics and previews.

    Distance Estimation Pipeline

    Pin-hole geometry, smoothing filters, and calibration values are combined into the distance and angle estimate output.

    Capture Workflow

    UI capture requests are submitted to the capture API and persisted to disk with metadata for analytics review.

    Demo Guide

    Ready for live walkthrough

    1. Open the dashboard and confirm the live camera preview is visible.
    2. Run calibration with a known face width and a known distance reference.
    3. Capture a frame and review the saved session metadata in analytics.
    4. Use the evaluation page to compare distance estimates against the expected reference values.

    About OptiVue

    OptiVue is a production-oriented AI system for real-time monocular face distance estimation. It combines camera access, MediaPipe face mesh detection, calibration-aware geometry, and a responsive monitoring dashboard for rapid validation and deployment.
